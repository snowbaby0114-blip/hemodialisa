# Prettier Configuration

This project uses Prettier for consistent code formatting with the following configuration:

## Configuration (`.prettierrc`)

```json
{
  "semi": false,
  "trailingComma": "es5",
  "singleQuote": true,
  "printWidth": 100,
  "tabWidth": 2,
  "useTabs": false,
  "arrowParens": "avoid",
  "endOfLine": "lf",
  "plugins": ["prettier-plugin-tailwindcss"]
}
```

## Settings Explained

- **semi**: `false` - No semicolons at the end of statements
- **trailingComma**: `"es5"` - Trailing commas where valid in ES5 (objects, arrays, etc.)
- **singleQuote**: `true` - Use single quotes instead of double quotes
- **printWidth**: `100` - Wrap lines at 100 characters
- **tabWidth**: `2` - Use 2 spaces for indentation
- **useTabs**: `false` - Use spaces instead of tabs
- **arrowParens**: `"avoid"` - Omit parentheses when possible in arrow functions
- **endOfLine**: `"lf"` - Use Unix-style line endings

## Prettier Plugin: Tailwind CSS

The `prettier-plugin-tailwindcss` automatically sorts Tailwind CSS classes according to the [recommended class order](https://tailwindcss.com/blog/automatic-class-sorting-with-prettier).

### How It Works

**Before formatting:**

```tsx
<div className="rounded-lg bg-blue-500 px-4 py-2 text-center font-bold text-white">Button</div>
```

**After formatting:**

```tsx
<div className="rounded-lg bg-blue-500 px-4 py-2 text-center font-bold text-white">Button</div>
```

### Benefits

1. **Consistency** - Classes are always in the same order across the entire codebase
2. **Readability** - Easier to scan and understand class lists
3. **Automatic** - No need to manually sort or remember the order
4. **Merge Conflicts** - Reduces git conflicts from differently ordered classes
5. **Best Practices** - Follows Tailwind's official recommendations

### Class Order

The plugin sorts classes in this order:

1. Layout (display, position, etc.)
2. Box model (margin, padding, width, height, etc.)
3. Typography (font, text, etc.)
4. Visual (background, border, etc.)
5. Misc (transitions, transforms, etc.)

## Usage

### Format All Files

```bash
npm run format
```

### Check Formatting

```bash
npm run format:check
```

### Format Specific Files

```bash
npx prettier --write src/app/page.tsx
```

### Auto-format on Save (VS Code)

Add to your `.vscode/settings.json`:

```json
{
  "editor.defaultFormatter": "esbenp.prettier-vscode",
  "editor.formatOnSave": true
}
```

## Integration with Git Hooks

Prettier automatically runs on staged files during commit via Husky and lint-staged, ensuring all committed code is properly formatted.
